Smart Inventory System

Full stack web application for inventory management with real-time tracking, analytics and reports.

  • Spring Boot
  • Angular
  • MySQL

Full stack web application built to help small warehouses manage stock levels without spreadsheets. The Angular front end gives staff a live view of inventory across multiple locations, with low-stock alerts, category filtering and CSV exports. The Spring Boot backend exposes a REST API secured with JWT authentication, and MySQL stores stock movements so managers can generate historical reports and spot trends in demand over time.

Industrial Control System Simulation

Simulation of a full control system with plc, gui, communication protocols and PID controllers.

  • CODESYS
  • PLC Programming
  • Automation
  • C++
  • Modbus
  • SQL
  • PID Controllers

In this project I simulate a full control system, with PLC logic, communication protocols, GUI, data storage, analytics and PID controllers. The control system and analytics are developed with C++ and uses the Modbus protocol to exchange data between industrial devices, while the control flow is structured with ladder logic and structured text for sequential automation. SQL is used to store process data and historical events, allowing analysis and monitoring of machine behaviour before deployment to a physical installation. It serves as a demonstrtation of a real-world industrial control system, and can be used to test and validate the complete control logic before deploying it to a physical machine.
