Smart Inventory System

Full stack web application for inventory management with real-time tracking, analytics and reports.

  • Spring Boot
  • Angular
  • MySQL

Full stack web application built to help small warehouses manage stock levels without spreadsheets. The Angular front end gives staff a live view of inventory across multiple locations, with low-stock alerts, category filtering and CSV exports. The Spring Boot backend exposes a REST API secured with JWT authentication, and MySQL stores stock movements so managers can generate historical reports and spot trends in demand over time.

CODESYS Simulation

State Control Simulation

Simulation of a process control system for a machine that goes through different states.

  • CODESYS
  • PLC Programming
  • Automation

In this project I try to simulate a process control system for a machine that goes through different states. I integrated a manual, automatic and home modes, as well as a start and stop function, as the default operation modes. More can be added to the system, such as a reset function, a maintenance mode, and a fault detection system. The simulation is built in CODESYS using Structured Text (ST) and Sequential Function Chart (SFC) programming languages. It serves as a demonstrtation of a real-world industrial control system, and can be used to test and validate the control logic before deploying it to a physical machine.
